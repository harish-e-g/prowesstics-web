# Website: Photoreal UHD Image Prompts (v3)

Goal: images that look like a real commercial photoshoot, not AI art. Every prompt below is written the way a photographer briefs a shoot: real camera, real lens, real light, real people and real places.

---

## Before you start (read once)

**1. Set the style in ChatGPT first.** Paste this as your first message in a new chat, then send the prompts one by one in the same chat so every image matches:

> For this session you are a commercial photographer producing a corporate photoshoot for an Indian enterprise technology company. Every image must look like an unretouched frame from a real professional shoot: true-to-life colour, natural skin texture with pores and fine lines, real fabric creases, realistic reflections, accurate hands, slight natural lens vignetting and fine film grain. Never add glowing holograms, neon effects, floating UI, sci-fi elements, lens flares, plastic-looking skin, oversaturated colour or a "digital art" look. No text, no logos, no watermarks anywhere in the frame. Always generate at the largest size available.

**2. About 4K.** ChatGPT currently outputs at most around 1536 px on the long side. To reach true UHD (3840 x 2160), run each image through a free upscaler before sending it to me:
- **Upscayl** (free desktop app for Mac): choose "Real-ESRGAN / Ultrasharp" at 4x
- or **Photoshop**: Image > Image Size > Preserve Details 2.0, or Camera Raw Super Resolution

**3. If an image looks "AI", reply in the same chat with:** "Make it look like an unedited photo. Reduce smoothness, add natural skin texture and film grain, flatten the lighting slightly, remove any glow."

**4. Naming.** Save each file as its slot ID (for example `IMG-01.jpg`). Photos as JPG, cut-outs as PNG.
